# 🧠 Data Structures and Algorithms in Kotlin

This project is a personal collection of **Data Structures and Algorithms (DSA)** implemented in **Kotlin**. It serves as a learning resource and reference for common DSA problems, algorithmic patterns, and their Kotlin implementations.

---

## 📚 What This Project Covers

- ✅ Arrays & Strings
- ✅ Linked Lists (Singly, Doubly)
- ✅ Stacks & Queues
- ✅ Trees (Binary Trees, BSTs)
- ✅ Graphs (Adjacency List/Matrix, BFS, DFS)
- ✅ Sorting Algorithms (Bubble, Selection, Merge, Quick)
- ✅ Searching Algorithms (Linear, Binary)
- ✅ Recursion & Backtracking
- ✅ Dynamic Programming
- ✅ HashMaps, Sets, and Heaps
- ✅ Greedy Algorithms
- ✅ Sliding Window, Two Pointers, etc.
